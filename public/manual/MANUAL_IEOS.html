Sección 2

Ventajas de la Arquitectura Utilizada

React.js — Frontend de Alta Velocidad

  • Carga instantánea: Al ser una aplicación de página única (SPA), el sitio web no se recarga por completo cada vez que el usuario navega entre el catálogo y el inicio; las transiciones son fluidas e instantáneas.
  • Componentes Reactivos: El cambio de imágenes según el color del producto y la actualización del carrito en tiempo real ocurren sin latencia, mejorando radicalmente la experiencia de compra.

Supabase — Base de Datos y Backend Seguro

  • Datos en Tiempo Real: Las actualizaciones del inventario, stock y tasas de cambio se reflejan de inmediato gracias al motor relacional de Supabase basado en PostgreSQL.
  • Seguridad de Nivel Bancario: Toda la información de productos, proveedores y configuraciones del sitio está protegida mediante políticas de seguridad avanzadas (RLS), asegurando que solo los administradores autorizados puedan modificar datos.

Alojamiento en Vercel — Infraestructura en la Nube

  • Velocidad de Carga Global (CDN): El sitio web se almacena en servidores distribuidos globalmente. La página abrirá a la velocidad de la luz tanto en computadoras como en teléfonos móviles desde cualquier operadora.
  • Disponibilidad del 99.9%: Al estar alojado en la infraestructura en la nube de Vercel, el sistema no se cae ni se ralentiza ante picos altos de visitas simultáneas de clientes.
  • Costo de Mantenimiento Eficiente: La arquitectura permite que el costo de servidores para el volumen actual de la empresa sea extremadamente bajo o incluso cubierto por capas gratuitas, eliminando costosos planes de hosting tradicionales.

Garantía y Respaldo (Backups)

El sistema incluye un módulo automatizado de copias de seguridad de datos (backups diarios) gestionado por Supabase, garantizando que su inventario, historial de proveedores y configuraciones estéticas estén siempre protegidos ante cualquier eventualidad.

Stack tecnológico

React.js Next.js TypeScript Tailwind CSS Supabase / PostgreSQL Vercel (CDN global) WhatsApp Business API OpenStreetMap

El administrador hace clic en Descargar plantilla para obtener un archivo estructurado con el orden de columnas exacto y una pestaña secundaria con instrucciones de llenado.

El usuario arrastra su archivo o hace clic en la zona central de carga. El sistema valida formatos .xlsx, .xls y .csv. Al presionar Importar, el sistema crea y procesa los productos de forma simultánea.
